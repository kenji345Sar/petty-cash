## 全体像

店舗ごとに **金庫（Safe）** が1つあり、各金庫は **小口** と **売上金** の2つの出納を持ちます。
この2つは業務としては別物です。小口は経費の立替・精算、売上金はレジの釣銭準備と売上の回収・引き渡しを記録します。金庫という置き場所を共有しているだけで、残高も帳簿も分かれています。

```
金庫（店舗ごと）
├─ 小口   … 店舗の小口現金。入出金と有高チェックを記録      → spec/03-petty-cash.md
└─ 売上金 … レジの釣銭・売上。バッグで現金を管理しつつ出納を記録   → spec/04-vendor.md
```

トップ画面で金庫を選び、「小口」「売上金」のタブを切り替えて操作します。
入力と一覧は**同じ画面**にまとまっています（入力フォームは画面内で開閉）。

## 用語

| 用語 | 意味 |
|---|---|
| 金庫（Safe） | 店舗ごとの現金管理単位。小口残高と売上金残高を持つ |
| 小口 | 店舗の小口現金の出納 |
| 売上金 | レジの釣銭準備と売上の回収・引き渡しの出納。バッグ（後述）と紐づく。コード上は `Vendor`（`vendor_transactions` など） |
| 業者 | 売上金を引き渡す相手（警備会社・銀行など）。画面の「売上金」タブとは別の意味 |
| 出納帳 | 取引と有高チェックを時系列（番号順）に並べた一覧 |
| 金種 | 紙幣・硬貨の種類（10000〜1円）ごとの枚数 |
| 有高チェック | 実際の現金を金種で数え、帳簿残高と照合する操作。差額を記録 |
| 赤伝 | 過去取引を打ち消す逆仕訳。元取引は消さず、反対の取引を追加する |
| 残高（balance） | 各取引時点での running balance。取引行ごとに保持 |
| バッグ | 売上金側の現金のまとまり。両替金バッグ / 売上バッグ / 準備バッグの3種（[04-vendor.md](./04-vendor.md)） |
