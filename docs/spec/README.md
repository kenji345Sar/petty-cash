# 小口現金管理システム — 仕様書

このフォルダが**仕様書の本体**です。「何の画面で・何ができて・どんな業務ルールか」をここにまとめます。
コードの解説（DDD層・調査手順など）は [docs/architecture/](../architecture/) に、C# 学習ノートは [docs/csharp/](../csharp/) にあります。仕様を知りたいときはまずここを読んでください。

---

## 全体像

店舗ごとに **金庫（Safe）** が1つあり、各金庫は **小口** と **業者** の2つの出納を持ちます。

```
金庫（店舗ごと）
├─ 小口   … 店舗の小口現金。入出金と有高チェックを記録      → spec/petty-cash.md
└─ 業者   … 業者向けの現金。バッグで現金を管理しつつ出納を記録 → spec/vendor.md
```

トップ画面で金庫を選び、「小口」「業者」のタブを切り替えて操作します。
入力と一覧は**同じ画面**にまとまっています（入力フォームは画面内で開閉）。

---

## 画面マップ

| 画面 | 主な操作 | 仕様 |
|---|---|---|
| トップ | 金庫（店舗）の選択、業者/小口の残高表示、タブ切替 | このREADME |
| 小口タブ | 入出金登録 / 有高チェック / 出納帳閲覧 / 赤伝 | [petty-cash.md](./petty-cash.md) |
| 業者タブ | バッグ管理（釣銭/売上/準備）/ 出納帳閲覧 / 有高チェック / 赤伝 | [vendor.md](./vendor.md) |

小口・業者で共通する概念（金種・有高チェック・赤伝・残高・期間フィルタ）は [common.md](./common.md) にまとめています。

## 用語

| 用語 | 意味 |
|---|---|
| 金庫（Safe） | 店舗ごとの現金管理単位。小口残高と業者残高を持つ |
| 小口 | 店舗の小口現金の出納 |
| 業者 | 業者向け現金の出納。バッグ（後述）と紐づく |
| 出納帳 | 取引と有高チェックを時系列（番号順）に並べた一覧 |
| 金種 | 紙幣・硬貨の種類（10000〜1円）ごとの枚数 |
| 有高チェック | 実際の現金を金種で数え、帳簿残高と照合する操作。差額を記録 |
| 赤伝 | 過去取引を打ち消す逆仕訳。元取引は消さず、反対の取引を追加する |
| 残高（balance） | 各取引時点での running balance。取引行ごとに保持 |
| バッグ | 業者側の現金のまとまり。釣銭バッグ / 売上バッグ / 準備バッグの3種（[vendor.md](./vendor.md)） |
