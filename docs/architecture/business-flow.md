# 業務フロー

このシステムが扱う業務の流れをコードの説明なしに整理する。

---

## 登場するもの

| 名前 | 説明 |
|-----|------|
| 金庫 | 店舗ごとの現金管理の単位。残高は「業者」「小口」の2種類で管理する |
| 釣り銭バッグ | レジに渡す釣り銭をまとめた袋（CA-001 など） |
| キャッシュバッグ | レジから回収した現金をまとめた袋（BAG-001 など） |
| 準備バッグ | 複数のキャッシュバッグをまとめて業者に引き渡す袋 |
| 業者残高 | 釣り銭・キャッシュバッグの収支の累計 |
| 小口残高 | 小口現金の収支の累計 |

---

## 業者管理の流れ

業者管理は「釣り銭を用意してレジに渡す」「レジから現金を回収して業者に渡す」という2つの流れが軸になる。

### 開店・釣り銭準備

```
1. 釣り銭バッグを作成して金庫に入れる
       ↓
   業者残高が増える（入金）

2. 釣り銭バッグをレジに移動する
       ↓
   業者残高が減る（出金）
   バッグの状態: 金庫内 → レジへ移動済み
```

### 現金回収・業者引き渡し

```
3. レジから現金を回収してキャッシュバッグに入れる
       ↓
   業者残高が増える（入金）
   バッグの状態: レジ保管

4. キャッシュバッグを準備バッグにまとめる
       ↓
   残高の変動なし
   バッグの状態: 金庫へ移動済み

5. 準備バッグを業者（銀行等）に引き渡す
       ↓
   業者残高が減る（出金）
   バッグの状態: 引渡済み
```

### 有高チェック（残高照合）

```
6. 釣り銭バッグ / キャッシュバッグの中身を実際に数える
       ↓
   金種ごとの枚数を入力 → 合計金額を算出

   一致した場合: 記録のみ。残高変動なし
   差額があった場合: 差額分の調整取引が自動で記録され、
                    業者残高・バッグ金額が実数に修正される
```

---

## 1日の業務イメージ（業者管理）

```
朝
 └─ 釣り銭バッグを金庫から作成（入金）
 └─ 釣り銭バッグをレジへ移動（出金）

営業中
 └─ レジの現金が増えてきたらキャッシュバッグで回収（入金）

夜
 └─ キャッシュバッグを準備バッグにまとめる
 └─ 準備バッグを銀行・業者に引き渡す（出金）
 └─ 残ったバッグの有高チェック（差額があれば調整）
```

## 小口現金管理の流れ

小口現金は「会社の日常的な小口の支払い」を管理する。

### 入出金登録

```
入金: 小口現金の補充（会社から現金を受け取る）
       ↓
     小口残高が増える

出金: 事務用品の購入・交通費の精算など
       ↓
     小口残高が減る
```

### 有高チェック（残高照合）

```
金庫内の小口現金を実際に数える
       ↓
金種ごとの枚数を入力 → 合計金額を算出

一致した場合: 記録のみ。残高変動なし
差額があった場合: 差額分の調整取引が自動で記録され、
                 小口残高が実数に修正される
```

---

## 残高の構造

金庫の残高は「業者」と「小口」で独立して管理する。

```
金庫残高
├── 業者残高
│     入金: 釣り銭バッグ作成 / キャッシュバッグ回収
│     出金: 釣り銭バッグ移動 / 準備バッグ引き渡し
│     調整: 有高チェックで差額があったとき
│
└── 小口残高
      入金: 小口現金の補充
      出金: 小口現金の支払い
      調整: 有高チェックで差額があったとき
```

---

## 各バッグの状態遷移

### 釣り銭バッグ（ChangeBag）

```
作成（入金）
    ↓
金庫内 ──→ レジへ移動済み
```

### キャッシュバッグ（CashBag）

```
作成（入金）
    ↓
レジ保管 ──→ 金庫へ移動済み（準備バッグに含まれた）
```

### 準備バッグ（PrepBag）

```
作成（キャッシュバッグをまとめる）
    ↓
準備中 ──→ 引渡済み（業者に渡した）
       └→ 戻す（キャンセル）
```
